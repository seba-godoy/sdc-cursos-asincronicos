## 4. Decisión metodológica

Se utiliza un **filtro de cuatro dimensiones**, sin puntaje inventado:

1. **Resultado de la tarea:** ¿el recurso enseña la misma acción y entrega el mismo producto práctico o solo habla del tema?
2. **Público:** ¿equipos OSFL/fundaciones en Chile o estudiantes, empleados públicos, mipymes, emprendimientos o perfiles genéricos?
3. **Formato y acompañamiento:** asincrónico autónomo, vivo, mixto, recurso descargable, suscripción u oferta incierta.
4. **Competencia efectiva:** si el recurso es gratuito, de Simón de Cirene o un servicio humano, debe distinguirse del curso asincrónico pagado que se quiere evaluar.

La clase `SUSTITUTO_PARCIAL_POTENCIAL` es deliberadamente conservadora: **no asigna equivalencia total**. Cada fila conserva tarea, público, formato original, precio publicado, enlace y una explicación del límite.

**Límite documental:** solo se revisaron de nuevo 14 páginas públicas; los otros 174 casos se evaluaron a partir de la ficha guardada O, que puede estar desactualizada o incompleta. No se inspeccionaron las actividades dentro de plataformas con login. No se validó que los 204 registros no cribados carezcan de sustitutos.
