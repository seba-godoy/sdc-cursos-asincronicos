## Por qué se hizo una compilación separada

El compilador de UX-10.3 mantiene un baseline **v1.0.12 inmutable**: 1.848.239 bytes y SHA-256 `82f57a273302275b2458f854fbb7a583f674b578f0fbd5ef063b09bf7515e7c7`. Cambiar los archivos CSS/JS originales rompería las pruebas que protegen la versión ya aprobada.

UX-11.4 incorpora **tres fuentes nuevas** sin modificar el HTML/CSS/JS/datos originales:

- [Interfaz UX-11.4](../src/ux11_4/render_concepts.js), solo para Conclusiones Cruzadas.
- [Estilos UX-11.4](../src/ux11_4/conclusions.css), solo para Conclusiones Cruzadas.
- [Compilador aislado](../scripts/build_ux11_4.py), que primero verifica byte a byte el baseline de producción, sustituye solo el renderer de Conclusiones Cruzadas e incorpora las seis fichas UX-11.3 en JSON local.

**Resultado:** nuevo archivo HTML autónomo en `dist/ux11_4/index.html`, con manifiesto y SHA-256 propios, distinto de v1.0.12. El empaquetado no se despliega automáticamente, no exige cuentas y no incluye claves ni servicios externos para funcionar. Los tres bloques JSON canónicos de 392 O, 709 B, 24 D y 6 C se conservan **idénticos byte a byte**.
